## Astuce la plus rapide
Beaucoup de ces logos sont disponibles en SVG monochrome sur des librairies libres :
- **Simple Icons** — simpleicons.org (télécharge le SVG, renomme-le comme ci-dessus)
- **Lobe Icons** — icons.lobehub.com (spécialisé logos IA : Claude, GPT, Gemini, Mistral, Perplexity…)

Les logos sont affichés tels quels ; en mode sombre ils sont automatiquement passés en blanc.
Si tu préfères, je peux aussi installer une librairie de logos (`simple-icons`) pour tout brancher automatiquement — dis-le moi.
